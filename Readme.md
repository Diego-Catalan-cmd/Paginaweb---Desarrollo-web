# ⚽ Premier League - Mejores Equipos

Este es un proyecto educativo de práctica de desarrollo web que muestra una lista de los equipos más importantes de la Premier League inglesa. El objetivo es practicar la estructura semántica de HTML5, el diseño con CSS (Flexbox/Grid) y la organización de carpetas.

## 📁 Estructura del Proyecto

El proyecto sigue una organización de archivos estándar para desarrollo web:

```text
/
├── index.html          # Estructura principal de la página
├── assets/             # Recursos del sitio
│   ├── css/            # Estilos
│   │   └── style.css   # Hoja de estilos principal
│   └── img/            # Logos de los equipos
│       ├── City.png
│       ├── liver.png
│       ├── arsenal.png
│       ├── united.jpg
│       └── chelsea.png
└── README.md           # Documentación del proyecto
